name: what-lasts
description: Separate the last agent answer into useful permanent and expiring information.
disable-model-invocation: true
---

Review the last agent answer using Morgan Housel's permanent-versus-expiring information distinction:

- **Permanent information** explains why something happens and is likely to recur. Keep only useful principles, causes, and patterns worth learning.
- **Expiring information** describes what happened or what is true under changeable conditions. Add a brief **recheck trigger** when one is evident.
- **Uncertain information** cannot be classified confidently from the available context.

Split mixed claims before grouping them. Extract the useful information instead of rewriting the answer.

Always show **Permanent information** and **Expiring information**; write `None found.` when either is empty. Show **Uncertain information** only when needed.

Use only the last agent answer. Do not browse, fact-check, save knowledge, or change the original answer.
